## Проверка каждого плана

- **PLAYOUT:** реализованный UI приведён к коду. Сохранены адаптив, контроль mic/cam, статусы загрузки/stale/мастера, hidden, mirrored local camera. Остались ручная приёмка физических устройств и проверки мобильной клавиатуры/доступности.
- **UNIFY_MODES:** добавлена таблица затронутых модулей. Включены Map clientId→несколько мест, remembered/restore, запрет второго clientId в ADD_PLAYER, старт/mid-game/handoff, names[] и валидаторы, локальные клавиши, UI keys/общая камера, сохранение всех счетов и финальный микс. Явно перечислены решения по стабильной идентичности места/изменению состава/версиям и регрессии.
- **JITSI:** проверена согласованность с jitsiConfig/invite/packPipe. Разграничены серверная инструкция, фактическая среда и два разных WebRTC-пути. Сервер/compose/nginx не запускались и не менялись; инструкция требует сверки конкретного stable-тега.
- **Исходное ТЗ CONTEXT:** сохранено как история; устаревшие «reload начинает заново», «вся кнопка после чтения», одно устройство не считаются актуальными задачами.
- **Апелляции, настройки, архив, оверлей:** отдельного детального плана раньше не было. В to-do добавлены необходимые решения, границы машины/сохранения/синхронизации и критерии приёмки. Автоапелляции по-прежнему отложены.
